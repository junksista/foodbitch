# Changelog

## 2026-10-28: Version 0.1
- Erste lokale Version: Tagebuch, Suche, Barcode, Gerichte, Ziele, Nährstoffe, Gewicht, Supplements, Backup.
- App-Icon: kleiner Burger auf rosa Hintergrund.

## 2026-10-28: Version 0.2
- Mengen in 5-g-Schritten, Plus/Minus rastet auf glatte 5er ein.
- „Kopieren“ an jeder Mahlzeit: standardmäßig dieselbe Mahlzeit am nächsten Tag, andere Ziele wählbar (auch mehrere).
- Smarte Vorschläge zählen nur vergangene Tage, nicht vorausgeplante Mahlzeiten.
- Updates kommen sofort an: Service Worker fragt eigene Dateien immer frisch ab.
- Produktsuche weicht bei Überlast auf den internationalen Open-Food-Facts-Server aus.
