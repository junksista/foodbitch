# Roadmap

## Phase 1: Lokale App (läuft auf einem Gerät)
- [x] Tagesansicht mit Frühstück, Mittag, Abend und optionalen Snacks dazwischen
- [x] Kalorien- und Protein-Ringe, Makro-Balken
- [x] Lebensmittelsuche: vegane Grundnahrungsmittel + Open Food Facts (vegan zuerst)
- [x] Barcode-Scanner
- [x] Gerichte anlegen (Zutaten, Portionen, optional Topfgewicht), Favoriten
- [x] Gericht mit einem Tipp für mehrere Mahlzeiten eintragen
- [x] „Wie gestern“ und „Als Gericht speichern“ aus einer Mahlzeit
- [x] Smarte Vorschläge: wiederkehrende Kombinationen → Gericht
- [x] Ziele: kcal, Protein (g oder g/kg), optional KH/Fett
- [x] Mikro-/Makro-Übersicht mit DGE-Richtwerten und Hinweisen auf vegane Kritiker (Tag / 7 Tage)
- [x] Supplements, die täglich mitzählen
- [x] Gewichtsverlauf
- [x] „Well done, bitch!“ mit Konfetti, freche Sprüche (abschaltbar)
- [x] Backup exportieren/importieren

## Phase 2: Zu zweit
- [ ] Supabase-Projekt anlegen (macht die Nutzerin selbst, Anleitung folgt)
- [ ] Login für beide (Magic Link per E-Mail)
- [ ] Sync von Tagebuch, Gerichten, Lebensmitteln (Gerichte + Lebensmittel geteilt, Tagebuch getrennt)
- [ ] Mahlzeit an die Partnerin schicken → erscheint bei ihr als Vorschlag zum Übernehmen
- [ ] Hosting (Netlify oder GitHub Pages) mit HTTPS, damit die Kamera auf dem iPhone geht
